This internship report presents the work carried out during the GIPEDI Internship at the Department of Electrical Engineering, Indian Institute of Technology Delhi. The internship focused on learning and implementing embedded system applications using Arduino UNO, sensors, displays, communication modules, and peripheral devices.

Several hardware projects were designed and simulated using Arduino IDE and SimulIDE. These projects include LED interfacing, seven-segment display control, LED matrix display, digital temperature monitoring, weather forecasting system, calculator applications, password-based security system, waveform generation using an R-2R DAC, Lissajous pattern generation, real-time alarm clock, motor automation, and temperature data logging using EEPROM and RTC modules.

The internship provided practical experience in microcontroller programming, sensor interfacing, digital and analog input/output, I\textsuperscript{2}C communication, EEPROM memory management, real-time clock applications, OLED graphics programming, and embedded system design. The projects strengthened the understanding of both hardware interfacing and software development while demonstrating practical engineering applications of embedded systems.

Overall, this internship significantly enhanced practical skills in embedded system development, circuit design, debugging, and real-time application development, thereby providing a strong foundation for future research and engineering projects.
